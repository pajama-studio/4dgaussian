# 单颗 Gaussian 检查器

入口：<https://4dgaussian.pajama.studio/?inspect=1#workbench>。支持中文和英文。

1. 点击场景中的像素。播放会暂停，默认选择对这个像素的 `T × α` 贡献权重最大的点；重叠候选下拉框可以换点。也可以输入原始 PLY 行号，检查暂时不可见的点。
2. 拖时间轴或换相机。ID 保持不变，观察它的世界位置、时间透明度以及屏幕轮廓如何变化。场景中的实线和虚线分别是 1σ、3σ 参考轮廓。
3. 用顶部“时间 / 形状 / 参数 / SH 颜色”按钮跳转。形状图放大显示 1σ 椭球，保留三轴比例和世界朝向；它的最长轴做了统一归一化。
4. SH 面板展示真实 RGB、推算 DC、基函数瓣状图、方向颜色球，以及逐项 `aY` 的 RGB 贡献。图可以拖动旋转，也支持聚焦后用方向键旋转。图示视角不改变求值方向。
5. 选择“教学 SH”可以调高阶系数，再取消“方向跟随场景相机”以独立改变输入方向。下载 JSON 保留全部原始字段、当前求值和外观模式来源。

## 数据边界

当前文件是 108,317 颗 Gaussian 的官方 STG-Lite `sear_steak` 样本，每行 32 个 float32。字段 `f_dc_0..2` 在此格式中是直接 RGB；**文件没有训练得到的高阶 SH 系数**。检查器先按现有 shader 将 RGB clamp 到 0–1，再用 `a0 = (RGB − 0.5) / (1/√(4π))` 转成数学上等价的 DC。合成的高阶系数只用于旁边的教学实验，不写回模型、不改变左侧渲染。

场景按已核实的 50 帧训练片段（50/30 秒）换算时间；PLY 不包含视频时长。检查器向 host 传递归一化时间，再由 host 换算秒数。`omega` 是四元数分量的时间变化系数，不能直接当作三维角速度。

## 代码链路

| 位置 | 作用 |
| --- | --- |
| `src/lib.rs` | 保留验证后的原始 32 字段记录，记录实际提交帧的相机、时间和排序，提供 WASM `splatRecord / inspectSplat / pickSplats` |
| `src/inspection.rs` | 与 `src/splat.wgsl` 对齐：时间权重 → 三次运动 → 四元数 → 协方差投影 → 屏幕高斯核 → Tα 排序 |
| `public/inspector-data.mjs` | 解码 42-float 当前状态、世界协方差、camera→center 方向和来源明确的 JSON |
| `public/inspector.mjs` | 选点、稳定 ID、双语、分区、教学系数与数据读数 |
| `public/inspector-viz.mjs` | 椭球、时间曲线、屏幕轮廓、16 个 SH 图案与颜色球 |
| `public/math/sh.mjs` | 复用数学手册中的 Graphdeco 实球谐约定与颜色求值 |

拾取使用同一帧的远到近排序，逆序累积透射率：`weight_i = T_i × alpha_i`，`T_next = T_i × (1−alpha_i)`。鼠标位置先换算成画布像素，再取该像素中心。候选列表保留点击时刻的权重；选中点的参数继续跟随当前时间和相机。这是 CPU 对当前光栅化规则的重算，不是精确的三维椭球射线相交，也不是从 GPU 读回的 ID。浮点阈值附近允许 CPU/GPU 微小差异。

投影保留现有 shader 的 `+0.3` 像素滤波、特征值下界、192px σ 上限、±3σ 方形 quad 边界、0.99 alpha 上限和 1/255 discard 阈值。轮廓是椭圆参考线，不能当作 quad 的完整裁剪边界。

检查器额外保留约 13.2 MiB CPU 原始记录。页面的“decoded PLY”是解压文件大小，不是总 CPU/GPU 内存测量。

## 验证

`npm run check` 包含：

- Rust 手算投影、letterbox、旋转椭圆的 Y 翻转、sigma 上限、透明度贡献排序、时间变化与退化四元数测试。
- `npm run qa:inspector`：读取真实 PLY 核对字段布局与行数、RGB/DC 各方向恒等性、教学系数来源、42-float ABI、协方差、候选解码与双语消息。
- 现有数学手册、SH 独立递推/积分/梯度验证、WASM 编译及网站静态检查。

线上浏览器另行检查选点、ID 时间追踪、相机、双语、系数编辑、图示旋转、导出及移动布局。数学测试不会代替这些交互检查。

2026-09-18 验证记录：完整 `npm run check` 通过，包含 8 个 Rust 测试；后续界面调整后，检查器的 97 条双语消息、脚本语法和静态检查再次通过。Cloudflare 版本 `93b83e1e-67b7-4570-abe9-395dbaa03ac9`。

线上 WebGPU 浏览器验证通过：直接点击保持 calibrated 相机、拖动切到 orbit、选中 ID 随时间/相机保持稳定、最后一个有效 ID 与越界 ID、32 字段、时间中心权重等于 1、SH 系数和独立方向编辑、16 基图、鼠标及键盘旋转、关闭/重开保留选择、英语面板无遗漏中文正文。1280×720 和 390×844 布局已查看，手机画布位于容器内且页面无横向溢出。文档页的 STG 渲染仍能运行，两个页面控制台均无错误。
