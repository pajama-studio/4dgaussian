# 4DGS Zero to Hero

入口：<https://4dgaussian.pajama.studio/learn/>。本系列以易理解的顺序讲授前向成像，再解释训练与导出；最终实操仍按数据 → 训练 → 导出 → 加载 → 渲染执行。

## 十二课主线

1. 照片与参数：完整前向/反向故事，实际 A/B 像素链。
2. 柔和基函数：归一化距离、指数衰减、协方差与激活。
3. 相机与屏幕椭圆：相似三角形、局部变化率、Jacobian、传统管线。
4. 像素合成：覆盖、透射率、排序、预乘 over 与计算型光栅器。
5. SH：方向、基函数、三列独立系数、RGB 合成与真实模型的区别。
6. 时间：归一化、三次运动、时间核、四元数、形变与四维条件化比较。
7. 数据准备：图像/相机/时间、SfM、缩放/裁剪内参、留出评估。
8. 梯度：完整标量链式法则、有限差分、位置的多条路径与离散分支。
9. 训练闭环：固定教师、同时更新、SGD/Adam、真实 50 次更新。
10. 密度控制：容量、复制/分裂/剪枝、单像素透明度反例。
11. 模型契约：32 浮点字段、激活一次、PLY 验证、导出与检查点。
12. 毕业实操：五点 PyTorch 训练、导出、原生 StgPass、CPU/GPU 对照、跨后端与性能。

每课有 5 个逐步解释、算例、易错点、实验、构建时提取的真实源码、自测与按选项反馈。现有 39 组 / 175 步数学推导仍通过 `/math/` 深链接访问。课程解释为本项目重新编写，不复制论文段落；模型特定细节链接原论文或原实现。

## 实现

- 内容：`scripts/learn/{rendering,learning,shipping}.mjs`；每段内容显式包含英文、中文。
- 构建：`scripts/build-learn.mjs` 生成首页与 12 个独立静态页面；复用自托管 KaTeX HTML + MathML。由 `npm run build:math` 在数学源码快照生成后运行。
- UI：`public/learn/course.mjs`、`course.css`。英文为无偏好默认，显式 `?lang=zh/en` 优先，其次沿用数学页语言偏好。英文切换按钮在左侧。
- 实验：`public/learn/labs.mjs`、纯计算 `models.mjs`。时间、像素与训练复用现有 `trace.mjs` / `training.mjs`，SH 复用 `sh.mjs`。
- 本机进度：`pajama-learn-progress-v1` 保存复习标记、每课所处解释步骤和最后课程；校验已存课程 ID。复习标记是自报记录，不是掌握评分；所有课可直接访问。
- 不保存训练参数到本机进度；语言切换和查看其他时间保留当前实验状态，重新加载会重置训练，并在页面说明。
- 页面不加载整个数学手册。全文公式仍横向可滚动，整页不应出现横向溢出。详细源码按需展开。

## 证据边界

- 新增课程实验包括一维核、球形投影、双层合成、SH 方向切片、时间核、内参缩放错误、标量梯度、双点 SGD、单像素复制与内存预算。每项说明其教学简化，完整可旋转 SH 实验仍在 `/math/#sh-lab`。
- 双点浏览器实验真实优化三个参数；不是五点 Python Adam 训练器，更不是官方真实场景训练。
- 密度课程展示合成反例，不声称实现原始 3DGS 或 STG 的完整密度控制。
- 原生宿主和 `StgPass` 是本仓库已有可运行示例；课程不把它描述成另一个自研引擎仓库的已完成集成。
- UI/UX Pro Max 的本地 `scripts` / `data` 是指向缺失位置的文本链接。使用已读技能中的无障碍/可读性准则以及真实浏览器走查，没有声称运行其设计系统检索。

## 验证

`npm run qa:learn` 验证双语内容完整性、公式构建、生成页面的本地资源/锚点、透明度两种遍历等价、相机算例、解析梯度与有限差分、复制透明度和字节预算。原数学检查继续独立验证 SH、投影、梯度、训练和翻译。

浏览器走查：12 课初始化；分步/展开、英中切换、具体错误反馈、复习标记及解释步骤刷新恢复；全部实验呈现数值且无控制台错误。双点训练一步 MSE 0.00403059 → 0.00384582，撤销恢复初始值；50 步为 0.00179457，切换语言与时间保持训练状态。

后续扩展方向：在不混淆表示契约的前提下增加真实训练日志回放、更多迁移练习、完整密度控制的独立实验，以及通过实际学习者测试调整节奏。当前版已提供从训练到渲染的完整课程主线。

最终响应式检查：375、768、1024、1440 CSS px 下正文 17px、整页无横向溢出；长公式在自己的容器滚动。手机首页课程目录默认折叠，让入口和学习目标优先出现。新增实验对应的纯计算函数也进入数学源码快照。
