Start with your first pixel从一个像素开始搭建

Create the project, run a known milestone, and name who owns every part of the frame.建立项目，运行确定的里程碑，说清一帧中每个部分由谁负责。

A viewer looks like a single application. Inside it are three jobs: the operating system provides a place to draw, the renderer turns data into pixels, and the interface supplies camera and time. We will build those jobs in that order. You do not need to know Gaussian calculus to clear a window.Viewer 看起来是一个应用，里面其实有三个工作：操作系统提供画布，渲染器把数据变成像素，界面提供相机与时间。我们按这个顺序搭建。不懂 Gaussian 微积分，也能先把窗口清成黑色。

2. Learn six Rust words as you meet them2. 先认识六个会遇到的 Rust 概念

A struct groups values, like a camera’s position and direction. An impl gives that group methods. &T borrows a value for reading; &mut T borrows it for changing. Option<T> means the value can be absent, such as a window before startup. Result<T, E> means an operation can fail; ? returns the error to its caller instead of silently continuing.struct 把数据装在一起，例如相机的位置和方向；impl 为它添加方法。&T 表示借用来读取，&mut T 表示借用来修改。Option<T> 表示可能还没有这个值，例如启动前的窗口。Result<T, E> 表示操作可能失败；? 会把错误返回给调用者，而不是带着错误继续。

async/await lets browser GPU initialization finish later without blocking the page. Arc<Window> lets the native app and GPU surface keep shared ownership of the same window. Neither keyword draws anything. They solve lifetime and scheduling problems around the renderer.async/await 让浏览器在等待 GPU 初始化时继续响应。Arc<Window> 让桌面应用和 GPU surface 共同持有同一个窗口。这些关键字本身不会绘图，它们解决的是渲染器周围的生命周期与调度问题。

3. Draw the ownership map before the pixels3. 先画职责图，再画像素

The browser host owns a canvas, fetch and requestAnimationFrame. The native host owns a winit window and OS events. Both create a WorkshopSurface. It owns the device, queue and presentation target and calls WorkshopPass. That pass owns shaders and buffers, with no dependency on a DOM or window.浏览器宿主负责 canvas、fetch 和 requestAnimationFrame；桌面宿主负责 winit 窗口与操作系统事件。两者都创建 WorkshopSurface，由它持有 device、queue 和显示目标，并调用 WorkshopPass。这个渲染 pass 持有 shader 与 buffer，不依赖 DOM 或窗口。

A buffer is GPU memory containing numbers. A shader is a program the GPU runs on those numbers. A render pipeline connects shader entry points to rules such as blending and output format. A command encoder records work; a queue submits it. Keeping these words separate makes a black screen diagnosable.Buffer 是存放数字的 GPU 内存，shader 是 GPU 用来处理数字的程序。Render pipeline 将 shader 入口与混合、输出格式等规则连接起来。Command encoder 记录工作，queue 提交工作。把这些名词分清，黑屏时才知道该查哪里。

4. Your first success is intentionally black4. 第一张正确的画面就是黑色

Stage 0 acquires the next surface texture, opens a render pass with LoadOp::Clear(BLACK), stores the result, submits commands and presents it. It issues no geometry draw. In the browser, “Presented frames” must increase while the draw count stays zero. This distinguishes a valid clear operation from a page that never initialized.阶段 0 获取下一张 surface texture，开启 render pass，用 LoadOp::Clear(BLACK) 清屏，保存结果、提交命令并显示，不调用任何几何绘制。在浏览器里，Presented frames 应递增，而绘制数保持 0。这能区分正常清屏和根本没初始化的页面。

    pub fn render(&mut self, input: Frame) -> Result<Option<u32>, String> {
        let frame = match self.surface.get_current_texture() {
            wgpu::CurrentSurfaceTexture::Success(frame)
            | wgpu::CurrentSurfaceTexture::Suboptimal(frame) => frame,
            wgpu::CurrentSurfaceTexture::Outdated | wgpu::CurrentSurfaceTexture::Lost => {
                self.surface.configure(&self.device, &self.config);
                return Ok(None);
            }
            wgpu::CurrentSurfaceTexture::Timeout | wgpu::CurrentSurfaceTexture::Occluded => {
                return Ok(None)
            }
            wgpu::CurrentSurfaceTexture::Validation => {
                return Err(
                    "Surface validation failed; reload to recreate the GPU resources".into(),
                )
            }
        };
        let count =
            self.pass
                .prepare(&self.queue, input, [self.config.width, self.config.height])?;
        let target = frame.texture.create_view(&Default::default());
        let mut encoder = self.device.create_command_encoder(&Default::default());
        {
            let mut pass = encoder.begin_render_pass(&wgpu::RenderPassDescriptor {
                label: Some("workshop-frame"),
                color_attachments: &[Some(wgpu::RenderPassColorAttachment {
                    view: &target,
                    resolve_target: None,
                    depth_slice: None,
                    ops: wgpu::Operations {
                        load: wgpu::LoadOp::Clear(wgpu::Color::BLACK),
                        store: wgpu::StoreOp::Store,
                    },
                })],
                depth_stencil_attachment: None,
                timestamp_writes: None,
                occlusion_query_set: None,
                multiview_mask: None,
            });
            self.pass.draw(&mut pass);
        }
        self.queue.submit([encoder.finish()]);
        self.queue.present(frame);
        Ok(Some(count))
    }
