04 / 12 · Build the splat构建 splat

Move numbers from Rust into GPU memory把 Rust 中的数字送进 GPU 内存

Build the Rust/WGSL data contract and draw one quad per instance.建立 Rust/WGSL 数据约定，让每个实例绘制一个四边形。

A shader cannot follow a Rust pointer to a Vec. We must explicitly copy bytes into GPU memory and tell both sides what those bytes mean. This is one of the most useful debugging skills in graphics.Shader 不能顺着 Rust 指针去读取 Vec。我们需要主动把字节复制到 GPU 内存，并约定每段字节的含义。这是图形开发最有用的排错能力之一。

1. Start with a byte ruler1. 先拿出“字节尺”

One f32 occupies four bytes. A vec4<f32> occupies sixteen. Our Instance has three vec4 blocks: center plus opacity, scale plus padding, RGB plus padding. Its stride is 48 bytes. The uniform contains a mat4 at bytes 0–63 and one vec4 at bytes 64–79, making 80 bytes. Rust repr(C), Pod and Zeroable make this explicit and checkable.一个 f32 占 4 字节，一个 vec4<f32> 占 16 字节。Instance 有三个 vec4 块：中心与不透明度、尺度与填充、RGB 与填充，步长共 48 字节。Uniform 的矩阵占 0–63 字节，vec4 占 64–79 字节，总共 80 字节。Rust 的 repr(C)、Pod、Zeroable 让这个结构明确且可检查。

Do not assume a Rust [f32; 3] and a WGSL vec3 will automatically produce the same struct offsets. WGSL alignment rules matter. Padding deliberately with vec4 blocks makes this first contract easy to inspect. The tests check actual Rust sizes, while GPU validation and pixel tests check the complete path.不要假定 Rust [f32; 3] 与 WGSL vec3 在结构体中的偏移天然一致，必须考虑 WGSL 对齐规则。先用 vec4 显式填充，让数据约定容易检查。测试检查真实 Rust 大小，GPU 验证和像素测试再检查整条链路。

2. Describe access before sending data2. 先描述访问方式，再发送数据

UNIFORM is for per-frame camera and stage values. STORAGE holds an array of instances. COPY_DST permits queue.write_buffer uploads. A bind group layout describes binding numbers and access types; a bind group connects those slots to actual buffers. Binding 0 and 1 must match the WGSL declarations.UNIFORM 存每帧的相机与阶段信息，STORAGE 存实例数组，COPY_DST 允许 queue.write_buffer 上传。Bind group layout 描述绑定编号与访问类型，bind group 再把插槽连接到真实 buffer。绑定 0、1 必须与 WGSL 声明一致。

3. Build a rectangle with two triangles3. 用两个三角形拼矩形

A quad is six vertex invocations: two triangles sharing two corner positions. vertex_index chooses a corner, instance_index chooses a Gaussian record. Stage 2 writes the selected record’s RGB directly and forces alpha to one, so the rectangle has a hard boundary. We have not applied the Gaussian function yet.四边形需要六次顶点执行：两个三角形共享其中两个角的位置。vertex_index 选择角，instance_index 选择 Gaussian 记录。阶段 2 直接写记录中的 RGB 并把 alpha 设为 1，所以矩形边缘是硬的。此时还没有使用高斯函数。

4. Upload what actually changes4. 上传真正变化的数据

For two toy records, copying 96 bytes per frame is easy to inspect. For a real model, repeatedly uploading every record wastes bandwidth. The production-facing StgPass keeps source records resident and uploads only a uniform and sorted source indices. Learn the small direct version first, then make that one change in ownership.对于两个教学记录，每帧复制 96 字节便于理解；对于真实模型，反复上传所有记录会浪费带宽。面向真实模型的 StgPass 让原始记录常驻 GPU，只更新 uniform 和排序后的源索引。先学直接的小版本，再改变数据所有权。
