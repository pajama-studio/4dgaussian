1. Write the contract before the decoder1. 先写约定，再写解码器

This fixture is STG-Lite: 32 little-endian float32 fields per record, 128 bytes. It stores position, temporal center/log-scale, unused normal slots, nine motion coefficients, three direct RGB features, opacity logit, three log-scales, quaternion wxyz and quaternion velocity. The field order is strict. This is not a universal 4DGS layout.本数据是 STG-Lite：每条记录 32 个小端 float32 字段，共 128 字节，包含位置、时间中心与时间对数尺度、未使用法线槽、九个运动系数、三个直接 RGB 特征、不透明度 logit、三个对数尺度、wxyz 四元数及其速度。字段顺序严格固定，这不是通用 4DGS 布局。

In this model the f_dc fields hold direct RGB features used by the lightweight renderer. Do not apply the static 3DGS SH-DC conversion just because the property names look familiar. The SH laboratory teaches a different appearance model; it does not add missing SH coefficients to this file.此模型的 f_dc 字段保存轻量渲染器使用的直接 RGB 特征。不要只因名字熟悉，就套用静态 3DGS 的 SH-DC 转换。SH 实验讲的是另一种外观模型，不会给这个文件补出不存在的 SH 系数。

2. Decode, validate, then activate2. 解码、验证，再激活

The strict parser checks header types/order, count limits, payload size, finite values and activation overflow. Only then upload the record array. Runtime scales use exp(log_scale); opacity uses sigmoid(logit). Passing log-scale directly into a covariance would square the wrong number.严格解析器会检查头部类型与顺序、数量上限、payload 大小、有限数值以及激活溢出，然后才上传记录数组。运行时尺度使用 exp(log_scale)，不透明度使用 sigmoid(logit)。若直接把 log-scale 塞进协方差，就会对错误的量平方。

3. Keep the source on the GPU3. 让原始记录常驻 GPU

StgPass::new uploads the source payload once. Each frame, prepare evaluates centers and opacity on the CPU, culls and sorts them, then uploads the ordered u32 indices. The shader uses each source index to read the original record and evaluates time-dependent geometry again. CPU and GPU evaluation must stay consistent or sorting will describe a different scene.StgPass::new 只上传一次原始 payload。每帧 prepare 在 CPU 上求中心与透明度、剔除并排序，然后上传排序后的 u32 索引。Shader 用源索引读取原始记录，再计算随时间变化的几何。CPU 与 GPU 求值必须一致，否则排序对应的是另一个场景。

At 108,317 records, source storage is 13,864,576 bytes, about 13.22 MiB. One full u32 index order is 433,268 bytes, about 0.41 MiB. Compressed download size is a separate number; neither value measures the complete process or GPU memory footprint.108,317 条记录的源数据占 13,864,576 字节，约 13.22 MiB；一份完整 u32 索引序列占 433,268 字节，约 0.41 MiB。压缩下载大小又是另一个数字，这两个数都不代表进程或 GPU 的总内存占用。

    pub fn prepare(
        &mut self,
        queue: &wgpu::Queue,
        frame: Frame,
        size: [u32; 2],
    ) -> Result<u32, String> {
        frame.validate()?;
        if size.contains(&0) {
            return Err("Cannot prepare a zero-sized target".into());
        }
        let (view, projection) = camera(frame, size[0], size[1]);
        self.stage = frame.stage;
        if frame.stage == 7 {
            let pass = self.real.as_mut().ok_or("Load the STG-Lite model first")?;
            self.count = pass
                .prepare(
                    queue,
                    frame.time,
                    view.to_cols_array_2d(),
                    projection.to_cols_array_2d(),
                    size,
                )?
                .visible_count as u32;
        } else {
            let data = instances(frame, view);
            self.count = data.len() as u32;
            queue.write_buffer(&self.instances, 0, bytemuck::cast_slice(&data));
            queue.write_buffer(
                &self.uniforms,
                0,
                bytemuck::bytes_of(&Uniforms {
                    view_projection: (projection * view).to_cols_array_2d(),
                    viewport_stage: [size[0] as f32, size[1] as f32, frame.stage as f32, 0.0],
                }),
            );
        }
        Ok(if frame.stage == 0 { 0 } else { self.count })
    }

    pub fn draw(&self, pass: &mut wgpu::RenderPass<'_>) {
        if self.stage == 0 {
            return;
        }
        if self.stage == 7 {
            if let Some(real) = &self.real {
                real.draw(pass);
            }
            return;
        }
        pass.set_pipeline(&self.pipeline);
        pass.set_bind_group(0, &self.bindings, &[]);
        pass.draw(0..if self.stage == 1 { 3 } else { 6 }, 0..self.count);
    }
