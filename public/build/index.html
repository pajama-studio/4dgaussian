Two ways to follow along两种跟学方式

Start online if your setup is not ready. When you can predict the result, clone the repository and reproduce it locally. Each chapter gives the next code change, a command, expected pixels, a fault to investigate, and an explanation you can check.环境没准备好，先在线运行。能预测结果后，克隆仓库并本地复现。每篇都给出下一步代码修改、运行命令、预期像素、需要排查的问题，以及可展开核对的解释。

The milestone selector runs the complete reference implementation in different teaching modes. The blog explains how to build up those capabilities; the modes are not separate Git history checkpoints.里程碑选择器在完整参考实现上切换教学模式；博客拆解这些能力如何逐步构建。这些模式不是彼此独立的 Git 历史检查点。
