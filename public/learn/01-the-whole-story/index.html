From photographs to a scene you can move through从照片，到可以自由观察的场景

Imagine arranging translucent, colored pieces of cotton until every camera sees the right picture. Each piece has a small set of numbers. Training adjusts those numbers; rendering reads them.想象你摆放很多带颜色、半透明的小棉团，让每台相机看到的画面都与照片一致。每团“棉花”由一组数字描述：训练修改数字，渲染读取数字。

Vectors & weighted sums向量与加权求和

STEP步骤 1 / 5

Start with the answer: pixels先从答案出发：像素

A photograph is a grid of RGB triples. A camera pose says where it was taken; intrinsics say how rays map to pixels. For a dynamic scene, a timestamp says when it was taken. The photograph does not directly tell us the 3D position of every visible detail.一张照片是一格格 RGB 数字。相机外参告诉我们在哪里拍、朝哪看，内参决定光线怎样映射到像素。动态场景还需要拍摄时间。照片本身并没有直接告诉我们每处细节的三维位置。

STEP步骤 2 / 5

Choose a representation选择能被调整的表示

A Gaussian stores a center, a shape, opacity and appearance. Many overlapping Gaussians describe a scene without mesh connectivity. They are soft basis functions, not little solid balls with a hard surface. One Gaussian usually contributes to many pixels, and one pixel receives many Gaussians.一颗 Gaussian 保存中心、形状、不透明度和外观。许多相互重叠的 Gaussian 不需要网格连接关系就能描述场景。它是柔和的基函数，不是有硬表面的小球。一颗点影响许多像素，一个像素也接收许多点。

STEP步骤 3 / 5

Run the forward trip沿前向路线算一遍

For time t, evaluate the moving primitives. Transform them into camera space, project their centers and shapes, decide which pixels they cover, and combine their colors in depth order. R names this entire renderer. Θ is simply the collection of all adjustable numbers; K and E are intrinsics and extrinsics.在时间 t 求出点的位置等状态，变换到相机空间，投影中心与形状，找出覆盖的像素，再按深度合成颜色。R 就是整套渲染计算的名字。Θ 只是所有可调数字的集合；K、E 分别表示相机内参与外参。

I^=R(Θ;K,E,t)\widehat I=R(\Theta;K,E,t)I=R(Θ;K,E,t)

STEP步骤 4 / 5

Reverse the question, not the video反过来提问，不是倒放视频

Compare the rendered picture with the target. A loss turns their difference into a number. Derivatives tell us how a small parameter change would change that loss. An optimizer then proposes new parameters. Repeat this loop across training views and times. The backward pass does not uniquely reconstruct the world from one image.比较渲染图和目标图，用损失把差别变成一个数。导数告诉我们微调某个参数时损失如何变化，优化器据此给出新参数。对多个视角和时间反复执行。一张图的反向传播并不能唯一还原整个世界。

STEP步骤 5 / 5

Separate learning from playback把训练与播放分清

A viewer needs trained parameters, a camera, a clock and a rasterizer. It usually does not need target photographs, gradients or optimizer state. Our real scene is a pretrained STG-Lite fixture. The small browser experiment is a separate synthetic training exercise; it is not how that real fixture was produced.播放器需要训练参数、相机、时钟与光栅器，通常不需要目标照片、梯度或优化器状态。本项目真实场景来自预训练 STG-Lite 模型；浏览器小实验是另一套合成训练任务，不是那个真实模型的训练记录。

A common wrong turn容易走错的地方

A lower training loss is evidence of fitting the observations. It does not by itself prove correct geometry or good unseen views.训练损失下降说明更贴近训练观测，本身不能证明几何正确或新视角表现良好。

The forward function consumes records and returns the pixel calculation.forward 接收记录并返回像素计算过程。

export function forward(records, time = defaults.time, pixel = defaults.pixel, options = {}) {
  const expected = options.target ?? target;
  const splats = records.map((row, id) => ({ id, ...evaluateRecord(row, time, pixel) }))
    .sort((a, b) => a.mean[2] - b.mean[2]);
  let remaining = 1, color = [0, 0, 0];
  for (const splat of splats) {
    splat.transmittance = remaining;
    splat.contribution = scaled(splat.color, remaining * splat.alpha);
    color = plus(color, splat.contribution);
    remaining *= 1 - splat.alpha;
  }
  color = plus(color, scaled(background, remaining));
  const error = color.map((v, i) => v - expected[i]);
  return { splats, remaining, color, target: [...expected], loss: dot(error, error) / 3 };
}
