One direction, three independent color sums一个方向，三组独立的颜色求和

After this lesson本课目标Read SH as weighted directional patterns and explain why separate channels produce a colored sphere.把 SH 看成方向图案的加权组合，解释独立通道为什么能组成彩色球。

A shiny surface looks different as you move around it. A single RGB triple cannot express that change. Instead, store a small recipe that takes a viewing direction and returns RGB.你绕着有光泽的表面移动时，看到的颜色会改变。单个 RGB 三元组无法表达这种变化，于是存一份小配方：输入观察方向，输出 RGB。

Vectors & weighted sums向量与加权求和Integrals & accumulation积分与累加

STEP步骤 1 / 5

Use a direction, not a position先得到方向，而不是位置

Subtract camera position from the Gaussian center and divide by the vector length. This produces a unit vector v: three numbers whose squared values sum to one. Our SH convention uses camera → Gaussian. Reversing it flips odd-degree SH terms, so sign conventions must match the exporter.用 Gaussian 中心减相机位置，再除以向量长度，得到单位方向 v：三个分量平方和等于 1。本教学采用相机 → Gaussian 的方向。方向取反会翻转奇数阶 SH 项，因此必须与导出端保持一致。

STEP步骤 2 / 5

Build with reusable patterns用固定的方向图案搭颜色

Spherical harmonics are fixed functions on the unit sphere. Degree zero is constant. Degree one supplies patterns proportional to −y, z and −x in our convention. Higher degrees provide finer angular variation. A coefficient says how strongly a pattern contributes; the pattern itself does not change for each Gaussian.球谐函数是在单位球面上的一组固定函数。零阶是常数；在本约定中，一阶分别与 −y、z、−x 成比例。更高阶表达更细的角度变化。系数决定某个图案占多大比重，基函数本身不会因 Gaussian 不同而改变。

STEP步骤 3 / 5

Repeat the sum independently for R, G and BR、G、B 分别做一次求和

For each direction, evaluate the basis once. Multiply those same basis values by three separate coefficient lists, then sum each channel. Up to degree L there are (L + 1)² basis functions. Degree three therefore needs 16 coefficients per channel, 48 scalar coefficients in total. Sharing basis values does not mix channels.每个方向只需算一次基函数，再分别乘 R、G、B 三列系数，各自求和。到 L 阶共有 (L + 1)² 个基函数。三阶就是每通道 16 个系数，总计 48 个标量。共用基函数并不意味着混合通道。

STEP步骤 4 / 5

Interpret the colored sphere correctly正确理解彩色球

Each point on the visualization sphere represents a direction, not a point on a physical Gaussian surface. At that direction, three scalar results become one displayed RGB color. The red-only, green-only and blue-only views expose the separate sums. Plot rotation changes how you inspect the function; it must not silently change its coefficients.可视化球面上的每个位置代表一个方向，不代表真实 Gaussian 表面的位置。在这个方向算出的三个标量合为一个显示 RGB。R、G、B 单独视图展示各自的和。旋转图示相机只是换角度查看函数，不应偷偷修改系数。

Match the actual appearance contract核对真实模型的外观契约

The +0.5 offset is an implementation convention. Our teaching evaluator follows Graphdeco’s nonnegative output clamp and then separately clips to 0–1 for display. The STG-Lite fixture in our viewer stores direct RGB, not learned higher-order SH. These are the actual 16 basis polynomials used by the SH lab.这是 SH 实验实际使用的 16 个基函数多项式。

export function shBasis(direction, degree = 3) {
  if (!Number.isInteger(degree) || degree < 0 || degree > 3) throw new RangeError('Degree must be 0..3');
  const [x, y, z] = unitDirection(direction);
  const pi = Math.PI, xx = x*x, yy = y*y, zz = z*z;
  const a = Math.sqrt(3 / (4*pi)), b = Math.sqrt(15 / (4*pi));
  const c = Math.sqrt(35 / (32*pi)), d = Math.sqrt(21 / (32*pi));
  const values = [
    C0,
    -a*y, a*z, -a*x,
    b*x*y, -b*y*z, Math.sqrt(5/(16*pi))*(2*zz-xx-yy),
    -b*x*z, Math.sqrt(15/(16*pi))*(xx-yy),
    -c*y*(3*xx-yy), Math.sqrt(105/(4*pi))*x*y*z,
    -d*y*(4*zz-xx-yy), Math.sqrt(7/(16*pi))*z*(2*zz-3*xx-3*yy),
    -d*x*(4*zz-xx-yy), Math.sqrt(105/(16*pi))*z*(xx-yy), -c*x*(xx-3*yy),
  ];
  return values.slice(0, (degree+1)**2);
}

public/math/sh.mjsL37–50

Each RGB component accumulates its own coefficient products.每个 RGB 分量分别累加自己的系数乘积。

export function sampleSH(coefficients, direction, degree = 3) {
  const basis = shBasis(direction, degree);
  if (coefficients.length < basis.length || coefficients.slice(0,basis.length).some(
    rgb => rgb.length !== 3 || !rgb.every(Number.isFinite))) throw new RangeError('Missing finite RGB coefficients');
  const contributions = basis.map((value,k) => coefficients[k].map(a => a*value));
  const raw = [0,1,2].map(ch => contributions.reduce((sum,rgb) => sum+rgb[ch],0));
  const shifted = raw.map(value => value+0.5);
  // Graphdeco's forward.cu clamps below zero; it does NOT clamp above one here.
  const shaderColor = shifted.map(value => Math.max(0,value));
  // A separate SDR display clipping step for this canvas demo (no tone mapping).
  const display = shaderColor.map(value => Math.min(1,value));
  return { basis, contributions, raw, shifted, shaderColor, display };
}
