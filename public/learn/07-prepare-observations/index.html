STEP步骤 1 / 5

A sample is more than an image一个样本不只是一张图片

Associate each target image with camera intrinsics, an extrinsic convention, timestamp, image dimensions and preprocessing. Masks and exposure settings may also matter. Keep filenames and camera IDs traceable. Training compares pixels produced using this exact camera and time against this exact target.每张目标图都要配内参、外参约定、时间戳、尺寸与预处理信息，必要时还要配遮罩和曝光设置。文件名与相机 ID 应能追溯。训练必须用这张图对应的相机和时间渲染，再与这张目标图逐像素比较。

STEP步骤 2 / 5

Estimate cameras and initialize geometry估相机，再初始化几何

Structure-from-motion can estimate cameras and sparse 3D points from matched image features. Triangulation intersects observations from different viewpoints. Those points are useful Gaussian centers, but moving objects violate a static-scene assumption; dynamic pipelines require appropriate calibration, synchronization and initialization. Neither Gaussian training nor COLMAP is a universal pose-repair button.运动恢复结构可通过图像特征匹配估计相机与稀疏三维点，三角化将多个视角的观测结合起来。稀疏点可作为 Gaussian 中心初值，但运动物体不满足静态场景假设；动态流程需要合适的标定、同步与初始化。Gaussian 训练和 COLMAP 都不是通用的相机修复按钮。

STEP步骤 3 / 5

Resize the camera with the image缩图也必须缩内参

If pixel coordinates scale by r, focal lengths and principal-point coordinates scale by r too. Cropping first subtracts the crop origin from the principal point. The lab uses the continuous image-coordinate convention. Pixel-center formulas can include half-pixel offsets; match your resampler rather than mixing conventions.像素坐标缩放 r 倍时，焦距与主点坐标也要缩放 r 倍。若先裁剪，则先从主点减裁剪起点。本实验使用连续图像坐标约定；具体重采样器的像素中心公式可能含半像素偏移，必须统一，不能混用。

STEP步骤 4 / 5

Reserve unseen evidence保留模型没见过的证据

Choose training and held-out cameras or times deliberately. Adjacent frames from the same video can be highly similar; a random frame split may test interpolation rather than new-view performance. Record what is held out. The browser’s allcam real fixture is not evidence of a held-out-camera benchmark.有意识地划分训练与未见过的相机或时间。同一视频相邻帧很相似，随机按帧划分可能主要考察插值，而非新视角能力。要记录到底留出了什么。浏览器 allcam 真实模型不能作为留出相机评测的证据。

STEP步骤 5 / 5

Check a known point before training先用已知点核对投影

Project a few known landmarks and overlay them on images. Check depth sign, image axes, focal units, quaternion order and time alignment. For a synthetic experiment, use a known teacher and separately held-out cameras/times so you can debug the loop before involving real reconstruction.先把几个已知地标投影到图像上，叠加检查深度正负、图像轴方向、焦距单位、四元数顺序和时间同步。合成实验可用已知教师模型，并单独留出相机和时间，先调通训练闭环，再处理真实重建。

PUT NUMBERS IN代入数字

An 800 × 600 image with fx = 600 and cx = 400 becomes 400 × 300. With no crop, fx′ = 300 and cx′ = 200. A point at X/Z = 0.1 moves from u = 460 to u′ = 230. Keeping fx = 600 would incorrectly predict 260.800 × 600 图像缩为 400 × 300，原 fx = 600、cx = 400，未裁剪时新 fx′ = 300、cx′ = 200。X/Z = 0.1 的点从 u = 460 变为 u′ = 230；若仍用 fx = 600，会错误预测为 260。

A common wrong turn容易走错的地方

A file named cameras.json does not establish whether its rotation is world-to-camera or camera-to-world. Read the schema and validate a projection.叫 cameras.json 的文件名不能说明旋转矩阵是世界到相机还是相机到世界。要读契约，并用投影验证。

export function createTrainingData() {
  const truth=initialRecords();
  truth[0][0]=1.12; truth[0][8]=0.8; truth[0][20]=0.2;
  const {width,height,left,top,times}=trainingSpec;
  return times.map(time=>({time,samples:Array.from({length:width*height},(_,i)=>{
    const pixel=[left+i%width+0.5,top+Math.floor(i/width)+0.5];
    return {pixel,target:forward(truth,time,pixel).color};
  })}));
}
