STEP步骤 1 / 5

Freeze the question before fitting the answer先固定题目，再拟合答案

The teacher creates 12 × 10 target pixels at each of three times: 360 RGB samples. The student starts from a different record. Only Gaussian A’s initial x, linear x-motion and opacity logit change. Gaussian B, camera, shape, other motion terms and target images remain fixed. This bounded task makes the cause of each improvement inspectable.教师在三个时间各生成 12 × 10 个目标像素，总共 360 个 RGB 样本。学生从不同记录开始。只改变 A 点初始 x、x 方向线性运动和 opacity logit；B 点、相机、形状、其他运动项和目标图保持固定。这样才能看清每次改善的原因。

STEP步骤 2 / 5

Forward, loss, backward, update前向、损失、反向、更新

Evaluate all samples using the current records. Average their MSE. Sum the analytic parameter gradients with the same averaging. Compute all new values from the same old records, then commit them together. Changing the first parameter before calculating the second gradient would be a different algorithm.用当前记录求所有样本，平均得到 MSE，用相同平均方式汇总解析梯度。所有新参数都根据同一份旧记录计算，再一起提交。如果改完第一个参数才算第二个梯度，就成了另一种算法。

STEP步骤 3 / 5

One iteration is not one explanatory click一次迭代不是一次讲解点击

The eight-stage experiment separates reading a sample, evaluating time, projection, rendering, loss, gradient, candidate update and updated render. A parameter update is committed only at the last stage. Going backward restores the exact old record. The simpler controls on this course page commit one whole iteration at a time.八阶段实验把读取样本、时间求值、投影、渲染、损失、梯度、候选更新、更新后渲染分开。只有最后一步提交参数，回退会恢复旧记录。本课程页的简化按钮每次提交一整轮迭代。

STEP步骤 5 / 5

Read loss alongside the image and the contract把损失、图像和任务边界一起看

Lower MSE should correspond to changes you can see in the error image. Real pipelines may combine L1, SSIM-based and regularization terms; that is not the same objective as this MSE lab. Our fixed two-Gaussian task has no density control, SH training or real-scene reconstruction. Convergence here demonstrates the loop, not production reconstruction quality.MSE 下降应能在误差图中找到对应变化。真实流程可能组合 L1、基于 SSIM 的损失及正则项，与本实验 MSE 不是同一个目标。双 Gaussian 固定任务不包含密度控制、SH 训练或真实重建。这里收敛证明训练闭环成立，不代表生产重建质量。

A common wrong turn容易走错的地方

Do not optimize against targets regenerated from the student after each step. That moves the goal and destroys the meaning of the fitting experiment.不要每步用学生的新参数重新生成目标，那会不断移动目标，破坏拟合实验的意义。

The batch computes actual image loss and accumulated gradients.批量求值计算真实图像损失与累积梯度。

export function evaluateTraining(records, data, withGradient=false) {
  let loss=0; const gradients=[0,0,0],frames=[];
  const count=data.reduce((n,frame)=>n+frame.samples.length,0);
  for(const frame of data) {
    const pixels=[];
    for(const sample of frame.samples) {
      const options={target:sample.target,finite:false};
      const position=withGradient?gradient(records,0,frame.time,sample.pixel,options):null;
      const result=position?.result??forward(records,frame.time,sample.pixel,options);
      loss+=result.loss/count;
      if(withGradient) {
        gradients[0]+=position.analytic/count;
        gradients[1]+=position.analytic*(frame.time-records[0][3])/count;
        gradients[2]+=gradient(records,20,frame.time,sample.pixel,options).analytic/count;
      }
      pixels.push(result);
    }
    frames.push(pixels);
  }
  return {loss,gradients,frames};
}

The update is simultaneous and uses pre-update gradients.更新同步提交，梯度来自更新前状态。

export function trainingIteration(records, data, rate=1) {
  if(!Number.isFinite(rate)||rate<=0)throw new RangeError('Learning rate must be positive');
  const beforeRecords=copyRecords(records),before=evaluateTraining(beforeRecords,data,true);
  const afterRecords=copyRecords(beforeRecords);
  // All gradients come from the same pre-update batch; commit simultaneously.
  trainingParameters.forEach((field,j)=>{afterRecords[0][field]-=rate*before.gradients[j];});
  const after=evaluateTraining(afterRecords,data);
  if(!Number.isFinite(after.loss)||!afterRecords.flat().every(Number.isFinite))throw new Error('Non-finite training state');
  return {beforeRecords,before,afterRecords,after,rate};
