After this lesson本课目标Distinguish optimizing existing parameters from changing representation capacity, without treating clone/split as exact preservation.分清调整现有参数与改变表示容量，并理解复制或分裂并不严格保图像不变。

One huge soft brush can cover a region but cannot describe every small edge. Moving that one brush forever may not solve the problem; sometimes you need more brushes in the right places.一支巨大的柔和画笔能覆盖大区域，却难以描出每个细小边缘。永远调整同一支画笔不一定能解决问题，有时需要在合适位置增加画笔。

STEP步骤 1 / 5

Parameters and capacity are separate参数与容量是两件事

Gradient descent changes values for existing primitives. Density control changes how many primitives exist and where optimization effort is available. Regions with persistent errors or large accumulated screen-space position gradients can motivate extra primitives, but large error alone does not identify its cause: pose mistakes or exposure differences can also create it.梯度下降改变已有点的数值，密度控制改变点的数量与可分配的表达能力。持续误差或较大的累积屏幕位置梯度可能提示增加点，但大误差本身不能说明原因：相机错误、曝光差异也可能导致误差。

STEP步骤 2 / 5

Clone small detail; split broad coverage复制细节点，拆分大覆盖

In the original 3DGS strategy, gradient statistics and scale help distinguish clone and split candidates. A clone adds capacity near a small primitive; a split samples smaller children around a larger one and removes the parent. Exact thresholds, scheduling and child initialization belong to that implementation. STG has its own temporal and guided-sampling strategies.原始 3DGS 策略结合梯度统计与尺度区分复制和分裂候选。复制在小点附近增加容量；分裂在较大点附近采样更小子点并去掉父点。具体阈值、时机与初始值由实现决定。STG 还有自己的时间与引导采样策略。

STEP步骤 3 / 5

Duplicating a layer changes opacity复制一层会改变不透明度

Two identical coincident layers with alpha a leave transmittance (1 − a)². Their combined alpha is 1 − (1 − a)², which is larger than a except at endpoints. For a = 0.5, the result is 0.75. Therefore cloning cannot be described as simply copying a point with no image change.两个完全相同且重合的 alpha = a 层，剩余透射率是 (1 − a)²，合成 alpha 为 1 − (1 − a)²，除端点外都比 a 大。a = 0.5 时结果是 0.75。所以不能把复制解释成“复制一颗点而图像完全不变”。

αpair=1−(1−a)2\alpha_{\rm pair}=1-(1-a)^2αpair​=1−(1−a)2

STEP步骤 4 / 5

A one-pixel correction is not a global solution单像素修正不是全局解

To preserve an original alpha A at one pixel using two equal children, solve (1 − a)² = 1 − A, giving a = 1 − √(1 − A). At A = 0.5 this is about 0.2929, not 0.25. Across an entire Gaussian footprint, a constant opacity adjustment generally cannot preserve every pixel, especially when children move or shrink. Optimization must refine the result.若用两个相同子层在某个像素保持原 alpha A，解 (1 − a)² = 1 − A，得 a = 1 − √(1 − A)。A = 0.5 时约为 0.2929，而不是 0.25。整个高斯覆盖范围里，单个固定 opacity 调整通常不能保证每个像素都不变，更何况子点还移动、缩小了。后续需要继续优化。

a=1−1−Aa=1-\sqrt{1-A}a=1−1−A​

STEP步骤 5 / 5

Remove unhelpful work and maintain optimizer state去掉无用开销，维护优化器状态

Pruning can remove persistently low-opacity or otherwise unsuitable primitives according to the selected method. Adding/removing rows must keep every parameter array, optimizer moment array and identity mapping aligned. Opacity resets and growth schedules affect optimization; they are not ordinary inference-time operations. Our course density lab is a compositing thought experiment, not a density-control implementation.剪枝按具体方法去除长期低 opacity 或不合适的点。增删行时，所有参数数组、优化器矩数组与身份映射都必须对齐。opacity 重置与增长调度会改变优化过程，不是普通推理操作。本课密度实验是合成原理实验，不是密度控制实现。

At one pixel with A = 0.5: duplicate unchanged → 0.75; assign each child A/2 → 0.4375; use 1 − √(1 − A) for each child → 0.5. The third equality is only the stated coincident one-pixel setup.某像素 A = 0.5：不变地复制得到 0.75；每个子层分 A/2 得 0.4375；每个设为 1 − √(1 − A) 才得到 0.5。第三个等式只针对这里约定的重合单像素情形。

A common wrong turn容易走错的地方

More Gaussians are not automatically better: count, overlap, memory and sorting cost all matter.点越多不一定越好，数量、重叠、内存与排序成本都要考虑。

The same alpha law explains why adding primitives changes their combined footprint.同一个 alpha 合成规律说明增加点为何改变合成覆盖。

fn fs_main(input: VertexOutput) -> @location(0) vec4<f32> {
  let power = -0.5 * dot(input.local, input.local);
  let alpha = min(0.99, input.color_opacity.a * exp(power));
  if (alpha < 0.0039215686) {
    discard;
  }
  return vec4<f32>(input.color_opacity.rgb * alpha, alpha);
