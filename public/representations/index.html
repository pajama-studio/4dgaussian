04 / KEEP THE LAYERS CLEAR

Formats and renderers are separate choices

PLY / SPZ / SOG / RAD

These describe storage or delivery. A smaller file does not by itself change a Gaussian’s geometric or appearance model. Check retained SH bands, quantization and runtime memory separately.

PlayCanvas formats ↗Spark LOD / RAD ↗

Rasterization / 3DGUT / 3DGRT

Projection and tracing are rendering choices with their own model assumptions. NVIDIA’s Vulkan testbed provides raster, ray-traced and hybrid routes plus sample assets. It is a separate native renderer, not our WebGPU backend.
